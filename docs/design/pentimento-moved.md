# Pentimento moved

The corpus documentation lived here, under `pentimento/docs/`, while the corpus
itself was being built. It now has its own repository.

Stegobench is a harness you run. Pentimento is a corpus you download and cite,
and a citation should point at the corpus rather than at the tool that made it.

The generators that build it stay here, because they are part of the harness.
`tools/IMAGES.md` records the exact container images that built v1.
